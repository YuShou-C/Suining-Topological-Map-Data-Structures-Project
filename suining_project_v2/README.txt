遂宁市景点地图服务系统
======================

一、项目简介
------------

本项目是《数据结构与算法课程设计》的实验项目，使用 Python 和 Tkinter
实现遂宁市景点地图服务系统。程序以遂宁市 10 个代表性地点为固定示例数据，
将景点和交通路径组织成无向多重图，并在窗口中绘制简易拓扑地图。

程序不依赖网络地图服务，地图上的经纬度用于计算景点的相对位置，不代表
真实比例尺。当前版本采用固定数据，界面主要用于路径查询和最优路径分析，
不提供景点或直接路径的编辑功能。

二、主要功能
------------

1. 简易地图显示
   - 显示 10 个遂宁市代表性地点及其编号、名称。
   - 根据经纬度将景点映射到 Tkinter Canvas。
   - 绘制景点之间的直接路径。
   - 使用颜色区分出行方式：
       绿色：步行
       蓝色：公交车
       橙色：自驾
   - 查询所有路径后自动高亮当前排序下的首条（最优）路径；单击列表任意行可切换高亮。

2. 所有路径查询
   - 选择起点和终点名称。
   - 查询两点之间所有不重复经过景点的简单路径。
   - 结果显示景点顺序、出行方式、总距离、总时间、总费用和途经景点数。
   - 可在“排序方式”中选择按路径长度、花费时间、费用或途经景点数重新排序。
   - 路径默认按照终点编号、途经景点数、时间、费用和路径边数显示。

3. 三类最优路径分析
   - 选择一个起点。
   - 分别计算到其他景点的：
       距离最短路径
       花费时间最短路径
       费用最少路径
   - 每类结果都会列出起点到各个可达景点的指标。
   - 计算完成后自动高亮首条可达路径；单击列表中的某条结果，可在地图上切换高亮显示该最短路径。

4. 数据结构和算法展示
   - 使用邻接表表示景点之间的连接关系。
   - 使用多重边支持同一对景点存在不同出行方式。
   - 使用深度优先搜索（DFS）查询所有简单路径。
   - 使用自定义链地址法 Hash 表保存路径信息。
   - 使用 Dijkstra 算法计算三类最优路径。

三、固定示例数据
----------------

景点：
1. 观音湖湿地公园
2. 广德寺
3. 灵泉寺
4. 遂宁市人民公园
5. 遂宁市博物馆
6. 圣莲岛
7. 涪江文化长廊
8. 西山森林公园
9. 遂宁市体育中心
10. 遂宁火车站

路径边的属性包括：
- 起点编号和终点编号
- 出行方式：步行、公交车、自驾
- 距离，单位为公里
- 时间，单位为分钟
- 费用，单位为元

程序中的路径按无向图处理，示例数据中的每条边在图中自动生成反向边。

五、核心实现说明
----------------

1. Graph
   Graph 使用 adjacency 邻接表保存图。每个景点编号对应若干条 Edge，
   一条 Edge 保存终点、出行方式、距离、时间和费用。

2. DFS 全路径搜索
   find_all_paths 从起点开始递归搜索。visited 集合保证同一条路径中
   不重复经过景点，因此即使图中存在环，也不会无限递归。

3. PathHashTable
   Hash 表长度等于景点数量。对于一个固定起点，路径按照终点编号取模，
   使用链地址法解决冲突。HashNode 通过 next 指针连接同一桶中的路径。
   插入时按“终点编号 → 途经景点数 → 花费时间 → 费用 → 路径长度”
   升序定位，保证同一桶内的链表始终有序。

4. Dijkstra
   dijkstra 使用优先队列，每次选择当前权值最小的景点继续扩展。
   通过更换边权函数，分别以 distance、time、cost 作为权值，
   得到距离、时间和费用三种最优结果。

5. 地图绘制
   Canvas 根据经度计算横坐标，根据纬度计算纵坐标。路径线条颜色表示
   出行方式；查询结果对应的路径使用红色加粗显示。

六、运行源码
------------

环境要求：Python 3.10 或更高版本，Windows 系统自带 Tkinter 通常即可运行。

在项目根目录打开 PowerShell，执行：

    cd src
    python main.py

七、运行测试
------------

在项目根目录执行：

    cd src
    python -m unittest discover -s . -p "test_*.py"

测试覆盖：
- DFS 简单路径查询
- Hash 表插入和查询
- Hash 桶内链表有序性
- 四种排序方式可用
- 路径长度排序算法
- Dijkstra 最优路径
- 10 个示例景点连通性
- 三种出行方式数据完整性

八、打包可执行文件
------------------

安装 PyInstaller：

    python -m pip install pyinstaller

在项目根目录执行（普通 Python 环境）：

    pyinstaller --onefile --windowed --name 遂宁景点地图 src\main.py

生成的文件位于 dist 目录。将 dist\遂宁景点地图.exe 复制到 bin 目录即可提交或运行。

注意：若使用 Anaconda，Tcl/Tk 的 DLL 位于 Library\bin 而非常见的 DLLs 目录，
直接打包后运行会报 “DLL load failed while importing _tkinter”。需要显式打包
Tcl/Tk 的 DLL 与脚本库（PowerShell，在项目根目录执行）：

    $env:TCL_LIBRARY = "$env:CONDA_PREFIX\Library\lib\tcl8.6"
    $env:TK_LIBRARY  = "$env:CONDA_PREFIX\Library\lib\tk8.6"
    pyinstaller --onefile --windowed --name 遂宁景点地图 --clean `
        --add-binary "$env:CONDA_PREFIX\Library\bin\tcl86t.dll;." `
        --add-binary "$env:CONDA_PREFIX\Library\bin\tk86t.dll;." `
        --add-data   "$env:CONDA_PREFIX\Library\lib\tcl8.6;tcl8.6" `
        --add-data   "$env:CONDA_PREFIX\Library\lib\tk8.6;tk8.6" `
        src\main.py

若尚未激活 conda 环境，请将上面的 $env:CONDA_PREFIX 替换为 Anaconda 的安装目录
（例如 D:\softwares\Anaconda）。bin\遂宁景点地图.exe 即是按此方法打包的。

本项目已经提供打包好的文件：

    bin\遂宁景点地图.exe

九、使用流程
------------

1. 启动程序，查看遂宁市景点简易拓扑地图。
2. 在右侧选择起点和终点，点击“查询所有路径”。
3. 在结果列表中查看路径信息，点击某条结果可在地图中高亮。
4. 只选择起点，点击“计算三类最优路径”，查看三种指标下的最优结果。

十、当前版本说明
----------------

- 景点和路径为固定示例数据，不支持运行时编辑。
- 地图为算法课程演示用拓扑图，不是真实导航地图。
- 所有路径搜索限定为简单路径，避免环路造成无限数量的搜索过程。
- 费用、距离和时间均为演示数据，仅用于算法计算和界面展示。
